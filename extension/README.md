# PhishTrap Gmail Bridge Extension

This optional Chrome Extension provides **1-click navigation** directly from your Gmail web interface into the local PhishTrap threat pipeline dashboard.

---

### How to Install in Chrome / Brave / Edge:

1. Open your browser and navigate to `chrome://extensions`
2. Toggle on **Developer mode** (top-right corner)
3. Click **Load unpacked** (top-left)
4. Select this directory:
   `/Users/harshita/Desktop/PhishTrap/extension`
5. Refresh your Gmail tab (`mail.google.com`)

---

### What it does:
- Makes all `PhishTrap/` label badges inside Gmail clickable to jump directly to your PhishTrap UI (`http://127.0.0.1:8080/?tab=gmail`).
- Injects a sleek **🛡️ PhishTrap Report** button right beside email headers to immediately inspect threat reports.
